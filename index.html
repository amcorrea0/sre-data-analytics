Cómo empezar

3 pasos. Sin PowerShell. Sin instalar nada raro.

1 · Descargar el repo (2 min)

  1. Abre VSCode (o instálalo desde code.visualstudio.com).
  2. Abre la paleta: Ctrl + Shift + P
  3. Escribe Git: Clone → Enter.
  4. Pega la URL: https://github.com/amcorrea0/sre-data-analytics.git
  5. Elige una carpeta de tu equipo (ej: C:\SRE).

Si no tienes Git en VSCode, te ofrece instalarlo en el primer intento.

2 · Crear el entorno virtual (3 min)

En VSCode: Terminal → Nuevo terminal. Selecciona CMD (no PowerShell) en el selector arriba a la derecha.

cd C:\SRE\sre-data-analytics
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python notebooks\generate_data.py

La primera vez tarda 2-3 min descargando paquetes. Las siguientes son instantáneas.

3 · Abrir el primer lab

En el explorador de VSCode (panel izquierdo), navega a notebooks/ y abre lab1_observabilidad.ipynb.

VSCode te preguntará qué kernel usar → selecciona Python Environments → .venv.

Si ves errores de kernel, ejecuta en el CMD: pip install ipykernel.

Durante la sesión

Los labs guiados (1 y 2) los abre el facilitador en pantalla grande. Tú sigues el flujo en tu laptop.

Los labs hands-on (3 y 4) los ejecutas en pareja y presentas tu headline ejecutiva al cierre.

El sitio publicado (amcorrea0.github.io/sre-data-analytics) tiene los notebooks renderizados: los puedes leer antes de ejecutarlos localmente.
